# כיווני פתרון

נסו קודם לבד. מטרת הפתרונות היא לאשר את המודל המחשבתי.

## תרגיל 1

`blocks = (1000 + 128 - 1) / 128 = 8`, ולכן מופעלים 1024 threads לוגיים. האינדקסים 1000 עד 1023 חייבים להיעצר ב-guard.

## תרגיל 2

גישה מחוץ לטווח עשויה להתגלות כ-invalid global memory access. העובדה שהרצה רגילה לא קרסה אינה הוכחת נכונות.

## תרגיל 3

הנוסחה היא `y = alpha * x + y`. בדיקת expected value צריכה להשתנות יחד עם הקלט, אבל רצוי לראות אותה נכשלת קודם כדי לוודא שהיא באמת בודקת משהו.

## תרגיל 4

אם יש N ערכים של 2, הסכום הוא `2*N`. reduction מלא ב-GPU מפעיל שוב את אותו רעיון על מערך הסכומים החלקיים עד שנשאר ערך אחד.

## תרגיל 5

Tile משפיע על מספר threads, שימוש ב-shared memory, registers ו-occupancy. יש למדוד; אין תשובה אוניברסלית.
